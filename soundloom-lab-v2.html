Soundloom Help

Make notes: Click empty grid cells to add notes and existing notes to remove them.

Instruments: Use + Instrument to add one and Instruments to switch sounds. Open Edit for undo, redo, copy, paste, and duplicate.

Pattern Library: Choose a drum beat, bass pulse, arpeggio, or chord starter. It adds notes to the matching category and keeps existing notes.

Note Editor: Opens a right sidebar listing each note's pitch, velocity, measure, and step. Select a note to change its velocity. The grid is locked against adding/removing notes until Note Editor is closed.

Grid spacing: Choose Fine, Medium, Default, or Wide. This changes visual spacing, not note timing.

Keyboard Controls: Open More → Keyboard Controls to customize shortcuts for menus and actions.

Play and save: Use Play, BPM, Save, and Load. Settings contains time signature, key, scale, dark mode, auto-save, and Whole Song View.
