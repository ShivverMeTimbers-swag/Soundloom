# Soundloom Studio

The definitive music playground — a Song Maker–style composer, with more depth.

**Highlights**
- Rainbow pitch-colored note grid with a piano-key ruler (click a key to hear it)
- Key & scale guide: out-of-scale rows are shaded, the tonic is highlighted
- Drums, Melody and Chords tracks with sampled instruments and a Chord Maker
- Big transport bar: play/stop, tempo slider, level meter, instrument switcher, undo/redo
- Export to **WAV** (mixed-down audio), **MIDI** (multi-track, GM instruments) or a Soundloom project file
- Loop sections, note velocity editor, pattern library, custom time signatures, dark mode, autosave
